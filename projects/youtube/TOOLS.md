# Free-first production tools

This is a shortlist, not a guarantee of unlimited free use. Check current quotas, export limits, regional availability, and commercial-use terms.

| Stage | Free-first method |
|---|---|
| Research | Public museums, universities, archives, libraries; maintain a source ledger |
| Script | Hermes via configured FreeLLMAPI |
| Voice | Test free/device TTS and listen for naturalness and pronunciation |
| Visuals | Public-domain or clearly licensed historical assets; otherwise original illustrations |
| Editing | CapCut mobile free tier or an editor already available on the phone |
| Subtitles | Editor auto-captions or free transcription quota, then manual correction |
| Thumbnail | Original design using an existing free editor |

Do not reuse another creator's video, narration, thumbnail, or music. Record asset URLs and license notes per episode.
