# Instagram — independent module

This project stays separate from YouTube.

## Niche
Faceless content around psychology, heartbreak, and long-distance relationships.

## Operating principles
- Keep content original, empathetic, and non-clinical unless qualified sources support a health claim.
- Avoid diagnosing viewers or presenting pop-psychology myths as facts.
- Use platform-compliant assets and music; verify current usage rights.
- Prepare hooks, reel/carousel structure, captions, and accessible on-screen text.
- Publishing and scheduling remain manual until explicitly configured and reviewed.
- Never expose private relationship details or personal information in public content.
